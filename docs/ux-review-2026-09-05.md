# Overflow UX changes for review

Release scope: 0.7.0. Deployment verification is recorded separately.

- Automatic low-allowance delegation is the primary requester flow. `/work`
  remains the manual shortcut. `/earn` is explicitly about earning credits now
  for later use; merely opening the dashboard does not start earning.
- The first earner interaction is a workspace choice. Recommend a subfolder of
  the current project; allow another explicit path. Use a full job ID below
  that root and reject escaping symlinks. No fixed home-directory workspace.
- Public work remains visible. Personal balances come from a cookie-authenticated
  endpoint backed by the same Google account ID as plugin OAuth. The public
  activity API no longer exposes balances, account ledgers, or credit aggregates.
- The new board uses original Mumbai shoreline artwork, muted sea-green controls,
  a compact work list and filters without counts. Sign-in adds your balance to
  the header; there is no account statistics panel. The account dropdown only
  identifies the signed-in person and offers sign-out.

## Verification

- 17 server tests passed, including account separation, invalid/expired sessions,
  browser-bound Google callback, replay rejection, logout origin checks, wrong
  Google audience rejection, and the existing plugin OAuth callback.
- Plugin and both skill validators passed. Worker deployment dry-run passed.
- Simulated usage readings: 16% stays quiet; 15% and 14% emit delegation notice.
- Local Worker serves the illustration (200) and rejects anonymous account reads
  (401).
- Chrome browser QA: populated and empty board states, filters, expanded task
  details, /earn clipboard, install dialog, sample-account session cookies,
  credits dropdown, sign-out, failure and recovery. No page overflow at desktop,
  354 CSS pixels, or 320 CSS pixels. Temporary viewport override was reset.
- Browser refresh previously replaced unchanged task rows. It now keeps those
  rows stable while updating elapsed times, preserving open details.
